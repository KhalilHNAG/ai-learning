## 🕳️ 踩的坑 / 学到的一课
| 坑 | 教训 |
|---|---|
| `argmax()` 打印成"第2位"实际是第3位 | **计算机从 0 数、人从 1 数**:索引结果给人看要 `+1`,给机器用保持 0 起始 |
| numpy 切片是**视图** | 切片/reshape 改的是原数组(和 Python 列表不同);要副本用花式索引、布尔掩码或 `.copy()` |
| `A * B` 以为在做矩阵乘 | `*` 是逐元素乘(形状必须一致);矩阵乘用 `@` 或 `np.matmul` |
| axis 方向易混 | `axis=k` = 沿第 k 轴折叠、该轴消失;axis=0 每列一个结果,axis=1 每行一个结果 |
