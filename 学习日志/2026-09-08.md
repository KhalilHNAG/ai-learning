## 🕳️ 踩的坑 / 学到的一课
| 坑 | 教训 |
|---|---|
| `plt.__version__` 不存在 | 包版本要从 `import matplotlib` 后用 `matplotlib.__version__` 取,`pyplot` 模块本身没有这个属性 |
| 短命令 `python` 在本机 shell 指向 Microsoft Store 的 WindowsApps 占位符,运行没输出 | 用完整路径 `C:\Users\Enhance\miniconda3\python.exe`(和交接文档"python 已指向 Miniconda"有出入,需要确认 PATH) |
| JupyterLab 实际带了 token,和文档写的"无 token"不一致 | 访问要带 `?token=...`;如需无 token 可用 `--ServerApp.token=""` 启动(待确认是否改配置) |
| 图里中文容易乱码 | 先图内英文、print 中文用 UTF-8,避免字体/编码两个坑一起踩 |
