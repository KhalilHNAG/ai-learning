每天学习结束时生成一份 `YYYY-MM-DD.md`(如 `2026-08-19.md`),模板如下:

```markdown
# 学习日志 · YYYY-MM-DD(Day N)

## 📌 今日主题
一句话:今天学的主要东西

## ✅ 完成了什么
- [ ] ...

## 🕳️ 踩的坑 / 学到的一课
| 坑 | 教训 |
|---|---|
| ... | ... |

## 📊 产出
- 仓库 commit / 文件 / 项目里程碑

## 📅 明天的计划
- [ ] ...

## 📝 一句话总结
```

**约定:**
1. 每天学习结束时对助手说"生成日志",助教会按当天对话内容整理
2. 有出入就口头修正,顺手 push 一次就好
3. 日志随代码一起提交,是"可追溯学习档案",复试/求职/组会都能用
