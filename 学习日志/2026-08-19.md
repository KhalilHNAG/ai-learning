## 🕳️ 踩的坑 / 学到的一课
| 坑 | 教训 |
|---|---|
| `python` 命令 9009/商店别名失效 | Windows 商店 Python 的别名可能坏;命令行入口要认准 miniconda |
| HTTPS 工具全部 `SEC_E_NO_CREDENTIALS` | 机器 schannel TLS 层损坏;curl/git 换 OpenSSL 后端、下载走 HTTP/清华镜像 |
| conda 26 要先 `conda tos accept` | 新版本服务条款拦截;本机实际用 pip 装包更顺 |
| pip 拒绝 HTTP 源 | 必须 HTTPS 或加 `--trusted-host`;已固定用 HTTPS 清华 PyPI |
| `(2,3)+(3,1)` 广播报错 | NumPy 广播规则:维度右对齐,不相等时其中一方必须为 1 |
| 打印 emoji `UnicodeEncodeError` | Windows 控制台默认 GBK;脚本开头 `sys.stdout.reconfigure(encoding="utf-8")` |
| 后台任务不继承工作目录 | 脚本里显式 `Set-Location` |
